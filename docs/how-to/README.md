# How-to Guides

Task-focused steps for people who already know what they want to do. For why things work the way
they do, see [Architecture](../architecture/README.md). New to the project? Start with the
[getting-started tutorial](../tutorials/getting-started.md).

| Guide | When |
|-------|------|
| [Apply a database migration](apply-a-database-migration.md) | Any schema change. |
| [Deploy and roll back](deploy-and-roll-back.md) | Shipping, or undoing a bad ship. |
| [Grant or revoke admin access](promote-an-admin.md) | Someone needs the seller console. |
| [Diagnose email that is not arriving](diagnose-email-delivery.md) | A receipt, digest or OTP went missing. |

Write a new guide when you find yourself explaining the same steps twice. Keep one task per page:
goal, prerequisites, numbered steps, how to check it worked.
